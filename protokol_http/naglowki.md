# Nagłowki odpowiadające
### content-type
 - Określa format danych, które są zwracane przez serwer

### date
- Podaje datę, godzinę i sekundę momentu zapytania

### server
- Zawiera informacje o oprogramowaniu serwera

# Nagłowki pytające
### :authority
- Jest używany w celu przekazania informacji o hostcie i porcie w żądaniu

### :method
- Określa metodę HTTP, która ma być użyta w żądaniu

### :path
- Zawiera ścieżkę URL, która jest żądana przez klienta
